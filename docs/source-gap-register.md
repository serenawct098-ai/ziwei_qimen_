# 來源缺口登錄

## 使用規則

本文件列出尚未具備完整、可追溯、可機讀正式資料的功能缺口。

缺口存在時：

- 不建立 0 byte JSON。
- 不建立空 `records` JSON placeholder。
- 不以程式硬編碼補足。
- 不以舊表、網頁、記憶、搜尋片段或猜測補值。
- 不建立第二份替代表。
- 對應功能在資料未完成前不得宣稱完成。
