## 適用範圍

本文件只規定傳統算法的層級、輸入依賴、讀表次序、排盤次序、推演次序與已鎖定裁定。

本文件不承載 GitHub 資料夾、部署、版本、Schema、審批狀態、測試程式、評分權重或文案。

紫微採南派三合十二宮骨架與已鎖定北派四化。奇門採時家、轉盤、拆補、寄坤二隨芮派。

# 1. 全局規則

## 1.1 雙軌分工

| 系統 | 時間基礎 | 主用途 | 不可混用 |
|---|---|---|---|
| 紫微斗數 | 出生資料；另以分析時間疊加限運 | 本命、長期結構、人生階段、流年節奏 | 問事時間、現居地不得改寫本命盤 |
| 時家轉盤奇門 | 問事時間與固定現居地 | 事件、時機、方位、短期發展 | 出生資料不得直接起時家局 |

## 1.2 全局執行順序

```text
輸入資料
→ 真太陽時
→ 紫微曆法 / 奇門四柱節氣
→ 紫微本命排盤 / 奇門起局
→ 紫微限運疊盤 / 奇門四盤完成
→ 各自推演
→ 各自評級
→ 雙軌整合
```

## 1.3 鎖定裁定

- 真太陽時完成後，才可進入農曆、干支、節氣、子時、閏月與起局。
- 紫微晚子時：真太陽時 23:00:00–23:59:59 視為次日子時；00:00:00–00:59:59 視為當日子時。
- 紫微閏月：初一至十五取原月；十六至月末取下一月；二十九、三十均取下一月。
- 紫微流月跨節氣：使用農曆月份原月干，不因跨節氣改月干。
- 奇門：冬至後至夏至前為陽遁；夏至後至冬至前為陰遁。
- 奇門：採拆補法，不採置閏法。
- 奇門：天禽本位中五，靜態寄坤二，動態與斷局隨天芮同宮飛布。
- 奇門：三奇六儀用同一干序，陽遁同向順布、陰遁同向逆布；不得把三奇另作反向飛布。
- 生年四化表與重忌定義完全依第 4.8 與第 5.7 執行，不得修改。

# 2. 原文、口訣與讀表層

## 2.1 紫微讀表順序

```text
命身宮訣
→ 十二宮固定序
→ 五虎遁表
→ 六十甲子納音五行局表
→ 紫微星定位表
→ 天府及十四主星定位表
→ 年干系星曜表
→ 年支系星曜表
→ 月系星曜表
→ 日系星曜表
→ 時系星曜表
→ 博士、歲前、將前、十二長生表
→ 宮干飛化表
→ 限運週期表
→ 格局與忌煞交沖表
```

## 2.2 奇門讀表順序

```text
節氣三元局數表
→ 陰陽遁九局地盤表
→ 六旬首遁儀表
→ 九星、八門本位表
→ 天盤九星轉布表
→ 值使遁宮表
→ 八門轉布表
→ 八神轉布表
→ 天禽天芮同宮規則
→ 旬空、驛馬表
→ 星門宮五行表
→ 十干剋應、格局表
```

## 2.3 讀表原則

- 每一步只可使用前一步已產生的結果。
- 同一顆星、同一宮、同一局只可有一個最終有效落點。
- 中五原始位與寄坤二有效位必須分開保存。
- 紫微十二宮、奇門九宮必須完整輸出；不可只輸出命宮、值符、值使或摘要。
- 推演層不得改寫排盤層已確定的星曜、干支、宮位、門星神與局數。
